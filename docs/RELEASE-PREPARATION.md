# Release preparation

All subsequent application source is saved on `release-prep`; `main` is unchanged. Temporary sandbox files and expiring download links are not the source of truth.

Scope: Edexcel linear International GCSE Double Award 4SD0 and Separate Sciences 4BI1/4CH1/4PH1; untiered exams with higher-demand practice. Secure accounts, private PDF processing, original question generation and criterion marking, timed mocks, evidence-based analytics, retrieval cards, consent-based friends/comparisons, friend games and private chat.

Release gates: reproducible build; regression and ownership/security checks; responsive browser-engine checks; configured Supabase and approved AI/OCR processing; real integration testing; privacy/retention/export/erasure and moderation operations; independent educational-quality evaluation.

Public signup and paid AI processing stay disabled by default. No database provisioning, paid service changes or public deployment is authorized by this source-code checkpoint. A passing offline build is not a production-readiness or zero-vulnerability guarantee.
